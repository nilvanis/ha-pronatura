# Development scripts

See the [development guide](../.devcontainer/README.md) for setup and usage.

| Script | Purpose |
| --- | --- |
| `setup.sh` | Create `.venv` and install development dependencies. |
| `develop.sh` | Prepare the local HA configuration and start Home Assistant. |
| `run_checks.sh` | Run Ruff linting, formatting checks, and unit tests. |
| `run_hassfest.sh` | Validate the integration with Docker on the host. |
